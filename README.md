# Zapphire

A lightweight, dark blue theme that brings the look and feel of Sapphire to
[Zed](https://zed.dev/).

I wanted to use the Sapphire theme after moving from VS Code to Zed, but it was
not available there. So I created Zapphire: a small, focused Zed theme inspired
by the colors and semantic highlighting of Sapphire.

## Features

- Deep navy editor and UI backgrounds
- Bright blue accents for keywords and operators
- Distinct colors for strings, numbers, functions, types, and properties
- Matching editor, panel, status bar, and terminal colors
- No runtime code or dependencies—just the theme

## Install locally

1. Clone this repository.
2. Open Zed's Extensions page with `Cmd+Shift+X` on macOS or `Ctrl+Shift+X` on
   Linux and Windows.
3. Select **Install Dev Extension**.
4. Choose the cloned repository directory.
5. Open the theme selector with `Cmd+K Cmd+T` on macOS or `Ctrl+K Ctrl+T` on
   Linux and Windows, then select **Zapphire**.
